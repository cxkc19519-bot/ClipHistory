# 分阶段开发计划

## 推进规则

- 每次开发只选择一个小步骤，完成、验证、记录后再进入下一步。
- 每个阶段均应产生可运行或可测试的成果。
- 当前阶段未通过验收时，不并行堆叠后续功能。

## 阶段 0：项目基线

1. [已完成] 检查 Windows 和 .NET SDK 开发环境。
2. [已完成] 创建解决方案、项目结构和基础测试项目。
3. [已完成] 配置格式、编译警告和基础 CI 预留规则；远程 CI 等 Git 仓库有效后接入。
4. [已完成] 最小 WPF 窗口已通过构建和启动验证，可正常创建窗口、关闭并以退出码 0 结束。

完成标准：干净环境下可构建，测试命令可运行，窗口可启动。

阶段状态：已完成。开发环境采用用户目录中的 .NET SDK，开发运行由 `dotnet` 主机加载应用；正式发布必须通过安装程序注册运行时，或生成自带运行时的发布包，不能假设目标电脑已配置开发环境。

## 阶段 1：核心数据模型

1. [已完成] 定义历史记录、内容类型和保存期限模型，并验证内容类型、UTC 时间及内容载荷约束。
2. [已完成] 实现文字、BGRA32 图片和 Windows 文件路径的 SHA-256 内容指纹与重复判断。
3. [已完成] 实现置顶、取消置顶、重复复制更新时间、稳定排序和精确过期规则。
4. [已完成] 为阶段 1 的每条业务规则编写单元测试。

完成标准：不依赖 UI 即可通过自动测试验证核心规则。

阶段状态：已完成。核心规则不依赖 UI、数据库或 Windows 剪贴板，严格构建和全部单元测试均通过。

## 阶段 2：本地存储

1. [已完成] 建立 SQLite 版本 1 初始结构、版本检查、事务初始化、应用数据目录和磁盘连接工厂。
2. [已完成] 实现事务新增、按 ID/内容指纹读取、可变状态更新、全量有序查询和可撤销删除基础。
3. [已完成] 实现图片应用私有存储、原子写入和安全路径删除。
4. [已完成] 实现安全的过期清理和图片清理失败报告。

完成标准：重启测试程序后数据仍存在；清理不触碰原始文件。

阶段状态：已完成。磁盘数据库重开持久化、图片存储和过期清理均已通过测试。

## 阶段 3：剪贴板监听

1. [已完成] 接入文字监听和再次复制。
2. [已完成] 实现自触发指纹抑制和文字去重。
3. [已完成] 接入图片监听、PNG 私有存储、缩略图与再次复制。
4. [已完成] 接入单/多文件及文件夹路径。
5. [已完成] 实现暂停和恢复记录。

完成标准：三类内容分别通过手工验收，重复复制不会增加重复项。

## 阶段 4：主界面

1. [已完成] 完成淡蓝色基础主题和窗口布局。
2. [已完成] 完成历史卡片和时间倒序列表。
3. [已完成] 完成置顶、取消置顶、删除和 5 秒撤销。
4. [已完成] 完成搜索和类型筛选。
5. [初步完成] 包含空状态、剪贴板错误提示和失效文件状态；发布前继续细化。

完成标准：用户能在主窗口完成全部核心历史操作。

里程碑状态：初步可用。已真实验证窗口启动、三类剪贴板捕获、图片落盘、重启持久化和正常退出；全部项目严格构建及自动测试通过。

## 阶段 5：Windows 集成

1. [已完成] 添加系统托盘及正确的关闭/退出行为。
2. [已完成] 添加可配置全局快捷键、冲突提示与旧快捷键恢复。
3. [已完成] 添加当前用户可选的开机自动启动。
4. [已完成] 添加单实例保护，避免多个进程同时监听。

完成标准：关闭窗口仍记录，托盘退出后停止，开机启动开关可逆。

阶段状态：已完成。系统托盘、快捷键、开机启动和单实例代码均通过严格构建。

## 阶段 6：设置与本地化

1. [已完成] 添加 1、3、5 天保存期限设置，默认 3 天。
2. [已完成] 添加中文、英文和跟随系统选项，支持立即切换。
3. [已完成] 添加清空普通记录与清空全部记录及二次确认。
4. [部分完成] 数据位置已写入 README；版本信息展示留待安装包阶段。

完成标准：设置重启后保持，语言切换无关键遗漏。

## 阶段 7：发布前稳定化

1. 执行完整自动测试和人工验收清单。
2. 验证异常剪贴板格式、大图片、大文本和大量记录。
3. 验证数据库损坏、磁盘不足和权限异常时的用户提示。
4. 检查性能、内存占用和隐私日志。
5. [进行中] 已生成自包含单文件版和中英文安装/卸载向导，并完成隔离安装、启动、卸载验收；升级覆盖测试尚待完成。

完成标准：核心验收场景全部通过，无已知数据丢失或隐私泄漏问题。

## 下一步

后续主要工作为正式安装/卸载向导、应用图标及更大规模的发布前人工稳定性测试。
