# 产品需求 V1.0

## 产品目标

ClipHistory 是一款 Windows 本地历史剪贴板软件。它在后台记录用户近期复制的文字、图片、文件和文件夹，并支持搜索、筛选、置顶、删除和再次复制。

## 已确认功能

### 内容记录

- 支持文字、图片、单个或多个文件及文件夹。
- 记录复制时间与内容类型。
- 相同内容只保留一条；再次复制时更新时间并移至对应区域顶部。
- 文件只保存原始路径，不保存文件本体。
- 文件已移动或删除时显示失效状态，不允许再次复制。

### 展示和使用

- 普通记录按时间倒序展示，置顶记录位于普通记录上方。
- 文字显示摘要，图片显示缩略图，文件显示名称、数量和路径。
- 点击卡片后将内容放回系统剪贴板，并提示“已复制”；用户自行按 `Ctrl + V` 粘贴。
- 支持按文字、文件名和路径搜索。
- 支持全部、文字、图片、文件、置顶筛选。

### 保存和删除

- 保存期限只有 1 天、3 天和 5 天，默认 3 天。
- 置顶内容永久保存，不参与自动清理。
- 取消置顶后，从取消置顶时间重新计算保存期限。
- 删除单条无需确认，但提供短暂“撤销”。
- 清空数据必须确认，并区分“普通记录”和“全部记录（含置顶）”。

### Windows 集成

- 关闭主窗口后继续在系统托盘运行。
- 仅从托盘菜单选择“退出”时停止程序和剪贴板监听。
- 支持可配置的开机自动启动，默认关闭。
- 默认使用 `Ctrl + Shift + V` 显示或隐藏窗口，允许修改快捷键。
- 支持暂停和恢复记录；暂停状态在主界面和托盘中清晰可见。
- 应用重启后默认恢复记录状态。

### 语言和隐私

- 支持简体中文、英文和跟随 Windows 系统语言。
- 切换语言后立即生效。
- 数据仅保存在本机；第一版不需要账号、云同步或联网。

## 第一版不包含

- OCR 图片文字识别
- 云端或多设备同步
- 用户账号
- 保存被复制文件的本体
- 自动向其他应用输入或粘贴
- 忽略指定应用
- 应用锁或历史数据加密

## 核心验收标准

1. 连续复制文字、图片和文件后，记录正确且顺序正确。
2. 重复复制不会产生重复项。
3. 点击任一有效记录后，可以在目标应用中通过 `Ctrl + V` 粘贴。
4. 搜索、筛选、置顶、取消置顶、删除和撤销均符合上述规则。
5. 过期清理不会删除置顶记录，也不会删除用户的原始文件。
6. 软件关闭窗口后仍能记录，彻底退出后不再记录。
7. 中英文界面不存在关键文本缺失或布局不可用。
