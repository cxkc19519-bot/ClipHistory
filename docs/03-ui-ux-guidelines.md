# UI/UX 设计规范

## 设计目标

- 简洁、直观、轻量，主要操作无需学习。
- 主色使用淡蓝色，背景使用白色或浅灰色。
- 使用圆角卡片，但避免过多装饰和动画。
- 正常窗口和较窄窗口下都能完成核心操作。

## 色彩基线

以下为初始建议，制作原型后可微调，但须保证文字对比度：

- 主色：`#75B8F7`
- 主色悬停：`#5CA7EE`
- 浅色背景：`#F5F9FD`
- 卡片背景：`#FFFFFF`
- 主要文字：`#1F2937`
- 次要文字：`#6B7280`
- 删除/危险：`#DC5A5A`
- 成功提示：`#2E9B69`

## 主界面结构

1. 顶部：搜索框、暂停/恢复、设置入口。
2. 筛选栏：全部、文字、图片、文件、置顶。
3. 置顶区域：存在置顶项时展示。
4. 普通历史列表：按最近复制时间倒序。
5. 底部临时提示：已复制、已删除及撤销操作。

## 卡片交互

- 点击卡片主体：重新复制。
- 置顶和删除使用独立按钮，点击不能同时触发卡片复制。
- 文字显示合理行数并截断，保留查看完整内容的方式。
- 图片保持比例生成缩略图，不阻塞列表滚动。
- 文件显示名称；多文件显示数量，并可查看路径列表。
- 键盘操作必须有可见焦点，常用操作提供工具提示。

## 状态设计

必须设计并实现以下状态：

- 首次使用/暂无记录
- 搜索无结果
- 正在暂停记录
- 文件路径已失效
- 图片加载失败
- 数据操作失败
- 快捷键被其他软件占用

## 本地化

- 所有用户可见文字进入资源文件，不在界面代码中硬编码。
- 中文和英文使用稳定的资源键。
- 布局需适应英文文本通常更长的情况。
- 日期和时间跟随当前语言与系统区域格式。

## 易用性

- 系统托盘使用与应用程序一致的软件图标，不使用 Windows 默认应用图标。
- 删除单项后撤销入口建议保留 5 秒。
- “清空全部”对话框明确说明是否包含置顶内容。
- 开机启动、保存期限等设置要说明实际影响。
- 动画应短且可忽略，不得延迟复制、搜索和删除操作。
